# Student Management REST API

## Overview
A RESTful backend application built with Spring Boot for managing
student records.

## Technologies
- Java
- Spring Boot
- Spring Data JPA
- Hibernate
- MySQL
- REST API
- Postman

## Features
- Create student
- Get student by ID
- Get all students
- Update student
- Delete student

## API Endpoints

POST   /api/student/create
GET    /api/student/get/{id}
GET    /api/student/getAll
PUT    /api/student/update/{id}
DELETE /api/student/delete/{id}
